# 특새 현장판 (Teuksae Live Board)

분당우리교회 특별새벽부흥회(특새)를 위한 **교회 공식 모바일 현장판** 데모.

> "성도가 현장과 온라인 중 자신에게 맞는 예배 자리로 안전하게 도착하고,
> 그날 붙든 말씀을 일상으로 가져가게 돕는 교회 공식 모바일 현장판."

앱스토어 앱이 아니라 카카오톡·홈페이지 링크로 바로 열리는 모바일 웹/PWA를 지향한다.

## 현재 상태

- `index.html` — 클릭 가능한 데모 목업 (성도 화면 + 운영자 화면). 정적 파일 하나, 의존성 없음.
- **개발 착수 전.** 이 데모는 교회 운영팀 설득과 개발 없는 모의운영(링크 + 운영자 단톡방)을 위한 도구다.
- 2026년 공식 특새 공지는 아직 없음 (2026-08-24 기준). 날짜·테마를 코드에 박지 않는다.

## 왜 "또 하나의 묵상·출석 앱"이 아닌가

2003~2025년 공식 게시판 글 867건, 댓글 1,488건(~110만 자) 분석 결론:

1. 특새는 콘텐츠가 아니라 몸으로 건너가는 순례다. 가장 명백한 미충족 수요는 설교 요약이 아니라 **신뢰할 수 있는 현장 정보**다 (새벽 2시부터 다락방 카톡으로 자리·문 개방 생중계).
2. 홈페이지·유튜브·카카오톡·가이드북·스티커·동판이 콘텐츠/기억의 역할을 이미 잘한다. 대체하지 않는다.
3. 본당을 상위 등급으로 만들면 안 된다. 드림센터·체육관도 같은 예배다.
4. 온라인은 열등한 대체품이 아니다 (입원·간병·돌봄·해외). 온라인 버튼은 현장과 같은 시각적 무게를 가진다.
5. 공개 기도·간증 피드는 만들지 않는다. 개인 기록은 기본 비공개·계정 없음·기기 내 저장.

자세한 조사 결과·검증 계획·성공/중단 기준: [`docs/PLAN.md`](docs/PLAN.md)

## 설계 원칙 (데모에 반영됨)

- 장소 상태는 6가지만: 준비 중 / 입장 가능 / 지금 권장 / 혼잡 / 입장 마감 / 확인 중
- 정확한 좌석 숫자, 사용자 제보형 혼잡 지도 없음 (잘못된 숫자가 군중 이동을 만든다)
- 모든 상태에 갱신 시각 + 담당자 확인 표시, 일정 시간 무갱신 시 자동 "확인 중" 전환
- 운영자 갱신은 버튼 한 번, 30초 이내. 모든 변경은 시각·담당자와 함께 기록
- 핵심 제품은 화면이 아니라 **현장 변화를 3분 안에 공식 갱신하는 운영 프로토콜**이다

## 첫 결정점

교회 운영팀이 장소별 상태를 공식 제공하고 갱신할 수 있는가.

- 가능하면 → "특새 현장판"을 만든다 (모의운영 통과 시 5일 이내 PWA 구축).
- 불가능하면 → 범용 묵상 앱으로 후퇴하지 않고 프로젝트를 중단한다.
