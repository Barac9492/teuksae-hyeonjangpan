# 특새 현장판

분당우리교회 특별새벽부흥회 기간에 사용할 **교회 공식 모바일 현장판** 데모.

> 예배 전에는 장소별 혼잡도와 안전 정보를 확인하고 참석 여부를 표시한다.
> 예배 후에는 받은 말씀을 오늘 실천할 한 가지로 정해 특새를 일새로 이어간다.

별도 앱 설치 없이 카카오톡이나 홈페이지 링크로 바로 여는 모바일 웹을 목표로 한다.

## 데모에서 확인할 수 있는 흐름

1. **예배 전**
   - 장소별 현재 상태와 마지막 확인 시간 보기
   - `오늘 참석`과 `내일 참석 예정`을 따로 받아 다음 날 자리 준비에 활용
   - 성도들이 누른 참석 버튼을 기준으로 현장·온라인 참석 인원 확인
   - 참석 장소 선택
   - 주차, 출차, 아이 동반, 배려 동선 확인
   - 셋로그처럼 성도들이 올린 2초 영상을 시간순으로 모아 보기
2. **예배 후**
   - 오늘 붙든 말씀 확인
   - 세 가지 제안 중 하나를 고르거나 직접 `오늘의 일새` 입력
   - 개인 말씀·기도 기록
3. **특새 주간**
   - 예배 참석과 일새 실천을 한 주 단위로 돌아보기
   - 다른 성도와 비교하지 않고 나만 확인하는 주간 기록
4. **운영자 화면**
   - 버튼 하나로 장소 상태 변경
   - 변경 시간과 담당자 확인

상단에서 `예배 전 04:17`과 `예배 후 06:12`를 눌러 두 화면을 모두 확인할 수 있다. 참석, 내일 참석 예정, 일새, 개인 기록은 브라우저 `localStorage`에만 저장된다. 현장 영상은 촬영 동의를 확인하고 운영팀 검수를 요청하는 단계까지 체험할 수 있다.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저로 열면 된다.

## 제품 원칙

- 정확한 좌석 수보다 담당자가 방금 확인한 상태를 제공한다.
- 본당, 드림센터, 체육관, 온라인은 같은 예배의 자리다.
- 참석 인원은 순위를 매기지 않고, 자리 준비와 오늘 함께 예배드리는 인원을 확인하는 데만 쓴다.
- 기도와 간증을 공개 게시판처럼 올리는 기능은 만들지 않는다.
- 오늘 특새 영상에는 반응이나 팔로우 기능을 넣지 않는다. 얼굴, 차량번호, 미성년자 정보가 드러나지 않도록 운영팀이 확인한 뒤 게시한다.
- 개인 기록은 공개하지 않고 이 기기에만 저장한다.
- 화면보다 현장 상황을 빠르고 정확하게 알리는 운영 방식이 더 중요하다.

자세한 조사 결과와 검증 계획은 [`docs/PLAN.md`](docs/PLAN.md)를 참고한다.
