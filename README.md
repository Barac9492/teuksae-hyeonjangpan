# 특새 현장판 (Teuksae Live Board)

분당우리교회 특별새벽부흥회 기간 전체를 연결하는 **교회 공식 모바일 현장판** 클릭 데모.

> 예배 전에는 공식 공간 혼잡도와 안전 정보를 확인하고 참석을 남긴다.
> 예배 후에는 받은 말씀을 오늘의 작은 실천으로 옮겨 특새를 일새로 이어간다.

앱스토어 앱이 아니라 카카오톡·홈페이지 링크로 바로 열리는 모바일 웹/PWA를 지향한다.

## 데모에서 확인할 수 있는 흐름

1. **예배 전**
   - 장소별 공식 상태와 마지막 갱신 시간 확인
   - `오늘 참석`과 `내일 참석 예정`을 따로 기록해 운영 인원 수요 예측
   - 실제 체크인 기준 현장·온라인 참여 인원 확인
   - 참석 공간 선택
   - 주차, 출차, 아이 동반, 배려 동선 확인
   - Setlog처럼 같은 새벽의 짧은 현장 순간을 시간순으로 공유
2. **예배 후**
   - 오늘 붙든 말씀 확인
   - 세 가지 제안 또는 직접 입력으로 `오늘의 일새` 결정
   - 개인 말씀·기도 기록
3. **특새 주간**
   - 예배 참석과 일새 실천을 한 주 단위로 돌아보기
   - 다른 성도와 비교하지 않는 개인 여정
4. **운영자 화면**
   - 장소 상태 원클릭 변경
   - 변경 시간과 기록 확인

상단의 데모 시간 전환으로 `예배 전 04:17`과 `예배 후 06:12` 흐름을 모두 확인할 수 있다. 참석, 내일 참석 예정, 일새, 개인 기록은 브라우저 `localStorage`에만 저장된다. 현장 사진·영상 제출은 동의 확인과 운영팀 검수 대기까지를 시뮬레이션한다.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저로 열면 된다.

## 제품 원칙

- 정확한 좌석 수보다 담당자가 방금 확인한 상태를 제공한다.
- 본당, 드림센터, 체육관, 온라인은 같은 예배의 자리다.
- 참석 수치는 경쟁이나 순위가 아니라 현장 준비와 공동체 감각을 위해 사용한다.
- 공개 기도·간증 피드를 만들지 않는다.
- 현장 로그는 좋아요·팔로워가 없는 당일 기록이며, 얼굴·차량번호·미성년자 정보 노출을 제한하고 운영팀 검수 후 게시한다.
- 개인 기록은 기본 비공개이며 계정 없이 기기에 저장한다.
- 핵심은 화면보다 현장 변화를 신속하게 공식 갱신하는 운영 프로토콜이다.

자세한 조사 결과와 검증 계획은 [`docs/PLAN.md`](docs/PLAN.md)를 참고한다.
