# 우리 · 2026 특별새벽부흥회

## 현재 루트 앱 (`/`, 2026-09-24)

공식 포스터 기반의 **예배 / 주차 / 기도 / 나눔 / 사진** 탭형 시안입니다. 엽서는 없으며, 간식 나눔 안에 `오늘 나눈 이야기`가 있습니다. 10월 5~10일, 04:40은 예배 시작입니다. 학교·체육관·본당 개방 시각은 별도로 확인해야 합니다.

루트 화면은 **현장팀이 저장한 주차·예배 공간 현황을 약 20초마다 확인하는 시범 운영 화면**입니다. 미입력·연결 실패·10분 넘은 정보는 이용 가능으로 표시하지 않습니다. 실제 운영값은 현장 담당자가 입력해야 합니다. 기도·나눔 이야기·사진은 여전히 내 화면 미리보기이며 서버 접수·공개 기능은 연결되지 않았습니다. 이 업데이트는 교회 공식 승인이나 전 교인 대상 출시를 뜻하지 않습니다.

최신 합의, 간식 운영 방식, 온수 정수기 이용 조건, 사진 저장 권장 구조와 남은 실행 조건은 [2026 앱 변경·데이터 경계](docs/2026-COMPANION.md)를 참고하세요. 이전 디자인 상황 미리보기는 `/?preview=1`에서만 이용합니다. 로컬 Vite만 실행하면 서버 현황은 연결되지 않으며 확인 전으로 표시됩니다.

기존 현장 운영 리허설은 `/app`에 보존되어 있습니다. 아래 Supabase 설정과 참석·개인 실천 기능은 **이전 `/app` 구현 설명**이며, 새 루트 화면의 작동 상태를 뜻하지 않습니다. 과거 홈페이지 기록은 [이전 홈페이지 안내](docs/LANDING-SCAFFOLD.md)에 남아 있습니다.

## 실행
```bash
npm install
cp .env.example .env.local
npm run dev
npm test
npm run lint
npm run build
node --check public/sw.js
```

`VITE_APP_MODE=local`은 `LocalAppRepository`만 사용합니다. `pilot`은 Supabase가 연결돼도 리허설로 표시하며, 설정이 없으면 안전하게 로컬 리허설로 돌아갑니다. `production`은 URL/anon key가 없으면 앱을 중지합니다.

## 이전 `/app` 데이터 경계
- 공유: 집계 참석 수, 장소 상태와 불변 로그, 비공개 검수 대기 미디어
- 기기 전용: `wordNote`, `prayerNote`, 선택한 실천, 실천 완료 기록, 우리 나눔 기록(카풀·간식·사진·감사 메모)
- 금지: 좌석 수, 리더보드, 연속 출석, 공개 피드/기도/간증, QR 출석, AI 설교 요약, 오픈 카풀 매칭

## 이전 `/app` 우리 탭

`우리` 탭은 다락방 단톡방에 보낼 것을 30초 안에 만드는 화면이다. 카풀·간식 문장 생성(앱은 매칭하지 않는다), 사진·영상 검수 대기 업로드, 운전자 잠 계산, 이름 없는 감사 한 줄, 기기 전용 나눔 기록으로 구성된다. 참석 인원은 같은 크기의 점으로 그린 '우리' 글자로만 보여 주며, 공식 승인 전 카드에는 "운영 리허설 · 예시 숫자"가 찍힌다. 나눔 기록은 세지도 비교하지도 않는다. 리뷰 기록은 `docs/reviews/`에 있다.

설정은 [운영 런북](docs/RUNBOOK.md), 보안 계약은 [백엔드 계약](docs/BACKEND-CONTRACT.md)을 참고하세요. 프로덕션 본문 제어는 `public/app-config.json`의 `officialApproved`, active event의 `official_approved`, `VITE_APP_MODE=production`이 모두 충족될 때만 공식 안내가 됩니다.

## 관리자 로그인

앱 상단 **관리자 로그인** 또는 `/admin`에서 로그인합니다. 슈퍼 어드민은 모든 현황과 팀 계정을 관리하고, 주차팀과 예배 공간팀은 자기 분야만 수정합니다. 같은 계정으로 여러 접속을 유지하며, 로그아웃은 현재 접속만 종료합니다. 입력자 표시명은 직접 기재한 값이지 검증된 개인 신원은 아닙니다.

현황은 DB에 저장되고 항목별 버전으로 충돌을 확인합니다. 작성 중 다른 담당자가 변경하면 최신 내용을 비교하기 전에는 덮어쓰지 않습니다. 같은 상태도 재확인해 시각을 갱신할 수 있습니다. 팀 비밀번호 설정·활성화는 슈퍼 어드민의 팀 계정 관리에서 합니다. 비밀번호 원문·DB 키는 공개 코드나 응답에 포함하지 않습니다.

설정과 보안 경계는 [관리자 인증](docs/ADMIN-AUTH.md), DB 및 API 계약은 [팀 운영](docs/TEAM-OPERATIONS.md)을 참고하세요.
